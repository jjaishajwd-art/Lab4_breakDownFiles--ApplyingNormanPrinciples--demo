# HCI Lab 4 — Norman's 7 Principles Demo(ADDITIONAL)

A simple web demo showcasing Norman's 7 Design Principles using HTML, CSS, and JavaScript.

## Principles Applied

| Principle | How |
|---|---|
| Visibility | Status box shows current progress |
| Feedback | Yellow flash + status text on click |
| Mapping | Green border status shows result |
| Constraints | Button disables after 3 clicks |
| Affordance | Blue rounded button looks clickable |
| Consistency | Yes/No dialog buttons same style |
| Error Prevention | Warning dialog before limit reached |

## Files

- `index.html` — Main page
- `style.css` — Styling
- `script.js` — Logic
